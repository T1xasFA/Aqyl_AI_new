# AqylAI

AqylAI — 7–11 сынып оқушыларына арналған математика оқу платформасы.

## Live site
https://t1xasfa.github.io/Aqyl.Ai-math-tutor-for-Tests/

## Google/SEO files
- `index.html` — SEO meta tags, canonical URL, Open Graph, structured data added
- `robots.txt` — allows crawling and points to the sitemap
- `sitemap.xml` — contains the public homepage URL
- `favicon.svg` — browser/search favicon

## GitHub Pages
Upload all four files to the **root of the repository**, alongside the existing Google verification HTML file.

After GitHub Pages deploys:
1. Open `https://t1xasfa.github.io/Aqyl.Ai-math-tutor-for-Tests/robots.txt`
2. Open `https://t1xasfa.github.io/Aqyl.Ai-math-tutor-for-Tests/sitemap.xml`
3. In Google Search Console → Sitemaps, submit `sitemap.xml`
4. In URL Inspection, inspect `https://t1xasfa.github.io/Aqyl.Ai-math-tutor-for-Tests/` and request indexing.
